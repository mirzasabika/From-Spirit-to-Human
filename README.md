From Spirit to Human — 3D Interactive Experience

An immersive 3D storytelling experience built using React, Three.js, React Three Fiber, GSAP, and Vite.
The project visualizes transitions between different spiritual and human forms with smooth animations, lighting effects, and scroll-based interactions.

Tech Stack
| Feature       | Library                                       |
| ------------- | --------------------------------------------- |
| UI Framework  | React                                         |
| 3D Rendering  | Three.js + React Three Fiber                  |
| Animations    | GSAP                                          |
| Build Tool    | Vite                                          |
| Deployment    | Vercel                                        |
| Asset Loading | drei (for loaders, cameras, lighting helpers) |

Features

Fully interactive 3D environment
Smooth scroll-based animations
Custom lighting and shadows
High-performance R3F + Vite setup
Optimized for deployment
Clean component-based scene structure
